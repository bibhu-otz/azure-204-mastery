# Lab: Deploy a Web App to Azure App Service

## Goal

Deploy a simple application to Azure App Service.

## Steps

1. Create a resource group.
2. Create an App Service Plan.
3. Create an App Service.
4. Deploy application code.
5. Configure application settings.
6. Enable logging.
7. Test the deployed endpoint.

## Interview Angle

Be ready to explain deployment slots, scaling, app settings, custom domains, and monitoring.
