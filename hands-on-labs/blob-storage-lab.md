# Lab: Upload and Read Files from Azure Blob Storage

## Goal

Practice Blob Storage operations from an application.

## Steps

1. Create a Storage Account.
2. Create a Blob container.
3. Upload a file.
4. Generate a SAS token.
5. Read the file from code.
6. Secure access using managed identity where possible.

## Interview Angle

Be ready to explain containers, blobs, SAS, access tiers, lifecycle policies, and private endpoints.
