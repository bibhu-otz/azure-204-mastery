# Lab: Create an Azure Function

## Goal

Build and deploy an HTTP-triggered Azure Function.

## Steps

1. Create a Function App.
2. Add an HTTP trigger.
3. Read configuration from application settings.
4. Return a JSON response.
5. Deploy using Azure CLI or VS Code.
6. Monitor logs in Application Insights.

## Interview Angle

Be ready to explain triggers, bindings, hosting plans, cold start, and Durable Functions.
