# Azure AZ-204 Certification Prep

A dedicated study repository for **Microsoft Azure Developer Associate (AZ-204)** certification preparation and Azure Developer interview practice.

## What this repo contains

- AZ-204 syllabus and study plan
- Topic-wise Azure tutorials
- Hands-on labs
- Interview questions and scenario-based questions
- Code sample folders for .NET, Node.js, and Python
- Cheatsheets and quick revision notes
- Mock interview preparation material

## Main Exam Areas

1. Develop Azure compute solutions
2. Develop for Azure storage
3. Implement Azure security
4. Monitor, troubleshoot, and optimize Azure solutions
5. Connect to and consume Azure services and third-party services

## Suggested Study Flow

1. Read the syllabus and exam objectives.
2. Follow the weekly study plan.
3. Complete tutorials topic by topic.
4. Practice hands-on labs.
5. Revise using cheatsheets.
6. Practice interview questions and mock interviews.
