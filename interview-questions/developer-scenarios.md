# Azure Developer Scenario-Based Questions

## Scenario 1

You need to build an API that scales automatically and requires minimal server management. Which Azure service would you choose?

**Expected Answer:** Azure App Service, Azure Functions, or Azure Container Apps depending on workload type.

## Scenario 2

Your application needs to store images uploaded by users. Which service should you use?

**Expected Answer:** Azure Blob Storage.

## Scenario 3

Your app needs to securely read secrets without storing them in code. What should you use?

**Expected Answer:** Azure Key Vault with Managed Identity.

## Scenario 4

You need asynchronous communication between microservices. Which services can help?

**Expected Answer:** Azure Service Bus, Event Grid, or Event Hub depending on the pattern.
