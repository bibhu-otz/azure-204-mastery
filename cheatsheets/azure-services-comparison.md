# Azure Services Comparison Cheatsheet

| Requirement | Recommended Service |
|---|---|
| Host web application | Azure App Service |
| Run event-driven code | Azure Functions |
| Store files/images | Blob Storage |
| Store NoSQL data globally | Cosmos DB |
| Store secrets | Azure Key Vault |
| Async enterprise messaging | Service Bus |
| Event-based routing | Event Grid |
| High-throughput event ingestion | Event Hub |
| API gateway | API Management |
| App monitoring | Application Insights |
